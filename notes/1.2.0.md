- **A change's file, at the line.** When Review or Diff points at a line of a merge request or pull request, Source opens that file as the change has it and scrolls to the line with it highlighted.
- **Which change, which commit.** The header says what you are looking at, such as "!123 · src/app.ts:42 at abc1234", so a file from a change is never mistaken for the one on disk.
- **A picked change follows the file you open.** With one change picked, opening a file shows it as that change makes it.
- **Comment on this line.** Right-click a line, or select some lines, to ask Review for a comment there.
- **Still read-only.** The file is read from the commit and nothing in your checkout changes.
