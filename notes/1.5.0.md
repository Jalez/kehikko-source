- **Search the file with ⌘F.** Press ⌘F in Source to open Kehikot's find bar. Every match in the file is highlighted and counted ("3 of 17"), and the view scrolls to the current one. Line numbers are left out of the search. Enter and ⇧Enter move between matches, and Escape closes the bar.
- **The file opens where you left it.** Each Source container remembers how far down the file you had scrolled, and comes back there when the kehikko is opened again.
- **No blank flash while a file is read.** Kehikot keeps its cover over the container until the file is drawn, then shows it whole.
- **A page that fails says so.** If Source ever fails to draw, Kehikot is told and shows what went wrong instead of an empty container.
