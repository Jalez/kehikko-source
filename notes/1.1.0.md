- **The file the canvas points at, shown.** Source shows the file you or another module pointed at, with syntax colours.
- **The exact passage.** When the canvas points at a range in a file, that range is highlighted and scrolled to.
- **Clear about everything else.** A folder, a file that is not text, or nothing pointed at gets one plain line saying so.
- **Read-only.** Source never changes a file; use Editor beside it to edit.
